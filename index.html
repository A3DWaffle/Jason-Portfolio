Flagship Work

Expanding Fronts Development

What began as a love of modding Genie Engine games grew into responsibility for the computer-player AI in a large, community-created expansion.

Turning Strategy Into Computer-Player Behavior

Expanding Fronts is a fan-made expansion for Star Wars: Galactic Battlegrounds, a real-time strategy game built on the Genie Engine. I have always enjoyed modding games built on this engine, especially their AI scripting systems.

The AI uses a rule-based language with Lisp-like syntax—not Lisp itself. Parenthesized commands such as (defrule) combine conditions, operators, and actions to evaluate the game state and control how the computer player responds.

I rewrote major parts of the AI and work on faction support, military population logic, resource gathering, builder behavior, technology advancement, and other strategic decisions. I also created a C++ constants generator that reduces repetitive work and manual errors in the scripts.

After learning the language in depth, I used JavaScript, TypeScript, and JSON to build Expanding Fronts AI Tools. The published VS Code extension catalogs the language and adds syntax highlighting, IntelliSense, hover documentation, signature help, rule folding, an outline, and basic diagnostics.

Featured Web Project

Quarter Quest Arcade

A multi-page arcade catalog that demonstrates my ability to combine visual design, server-side organization, and browser interaction.

An Arcade-Themed Website Built With C# and ASP.NET Core

Quarter Quest Arcade is a 1990s-inspired website featuring six original fictional games. Visitors can browse the catalog, search and sort titles, open individual game pages, save favorites, and submit ratings.

C# and ASP.NET Core organize the game information and page requests. Razor turns that information into reusable pages, while JavaScript handles immediate interactions such as searching and saved favorites.
