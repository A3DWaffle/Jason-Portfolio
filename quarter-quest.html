What I Built

More than a themed image

Quarter Quest is a working multi-page website, not just a visual mockup. Visitors can browse the catalog, open game pages, search and sort titles, save favorites, and submit ratings.

Search and sorting

Filter games by title or genre, then sort by title, year, rating, or vote count.

Quick View

Open any game in a focused window without losing your place in the catalog.

Individual game pages

Each game has its own page, and an invalid link displays a proper not-found response.

Favorites

Favorite games stay saved in the visitor’s browser between visits.

Star ratings

Ratings update each game’s average score and vote count.

Hall of Fame

A ranked page orders the games by average rating and uses vote count to break ties.

How It Works

Models/Game.cs
public class Game
{
    public int Id { get; set; }
    public string Title { get; set; } = string.Empty;
    public string Genre { get; set; } = string.Empty;
    public int Year { get; set; }
    public string Description { get; set; } = string.Empty;
    public string ImageName { get; set; } = string.Empty;
    public int[] Ratings { get; set; } = Array.Empty<int>();

    public int VoteCount => Ratings?.Length ?? 0;

    public double AverageRating =>
        VoteCount == 0 ? 0 : Ratings.Average();

    public string VoteLabel =>
        VoteCount == 1 ? "vote" : "votes";
}

01 · Game Information

A consistent format for every game

This file defines the information every game needs, including its title, artwork, description, and ratings. It also calculates the average rating and vote count automatically.

  • Default values prevent missing text from causing errors.
  • VoteCount and AverageRating always reflect the rating list.
  • VoteLabel chooses the correct word: “vote” or “votes.”
Takeaway: Keeping the game information and rating rules in one place makes the rest of the project simpler and more consistent.
Controllers/GamesController.cs
public IActionResult Details(int id)
{
    var game = games.FirstOrDefault(g => g.Id == id);

    if (game == null)
    {
        return NotFound();
    }

    return View(game);
}

public IActionResult HallOfFame()
{
    var rankedGames = games
        .OrderByDescending(g => g.AverageRating)
        .ThenByDescending(g => g.VoteCount)
        .ToList();

    return View(rankedGames);
}

02 · Page Requests

Opening the correct page

This file finds the game requested in the URL. If the game does not exist, it displays a proper 404 response. It also builds the Hall of Fame ranking.

  • The number in the URL identifies which game to open.
  • Missing games receive a proper not-found response.
  • The Hall of Fame sorts by rating, then uses vote count to break ties.
Takeaway: Each part has a clear job: finding a game, handling a missing entry, or building the rankings.

03 · Building the Catalog

One layout reused for every game

This page repeats the same card design for every game. Adding a new game automatically gives it the same layout and its own details link.

  • Each game’s information is inserted into the card.
  • The details button points to the correct game page.
  • The page includes the values JavaScript needs for searching and sorting.
Takeaway: I can add another game without copying and editing an entire block of HTML.
wwwroot/js/site.js
function filterGames() {
    const search = document
        .getElementById('gameSearch')
        .value.toLowerCase();

    const cards = document.querySelectorAll('.game-card');

    cards.forEach(card => {
        const title = card.dataset.title.toLowerCase();
        const genre = card.dataset.genre.toLowerCase();
        const matches = title.includes(search)
            || genre.includes(search);

        card.style.display = matches ? '' : 'none';
    });
}

function saveFavoriteIds(ids) {
    localStorage.setItem(
        'qqaFavorites',
        JSON.stringify(ids)
    );
}

04 · Page Interaction

Search and favorites that respond immediately

JavaScript filters the game cards as the visitor types. It also saves favorite games so they remain selected when the visitor returns.

  • Search matches both game titles and genres.
  • The original game cards remain available without the extra interactions.
  • Favorites can be remembered without requiring an account.
Takeaway: I used JavaScript where it improves the experience while keeping the main catalog straightforward.
